# Resume PDFs

This directory should contain two PDF files:

1. `resume-1page.pdf` - Your 1-page resume
2. `resume-2page.pdf` - Your 2-page resume

## To add your resumes:

1. Save your 1-page resume as `resume-1page.pdf` in this directory
2. Save your 2-page resume as `resume-2page.pdf` in this directory

The resume viewer component will automatically load and display these files when users click the "View Resume" button on the homepage.
